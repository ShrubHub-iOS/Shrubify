Shrubify current release: 4.1.2

The package version is defined once in control (Version: X.Y.Z).
Makefile generates GeneratedConfig.tweakVersion; EeveeSpotify.version and all
current in-app version labels read that generated value.

For each release:
1. Update control.
2. Update the README heading, current setup/testing guides, CHANGELOG and
   RELEASE-X.Y.Z.md; point README links at that current release document.
3. Run python3 scripts/check_release_consistency.py and the branding preflight.
4. Build new IPA/deb files with the normal release workflow. Never rename old
   binaries to imply they contain a newer tweak.
5. The workflow derives release titles, tags and asset names from control.
   The source generator derives download/version metadata from real releases.

Historical release records, old download URLs and migration/storage identifiers
retain their original values; they do not describe the currently installed build.
