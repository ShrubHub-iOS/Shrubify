# Shrubify 4.2.5~beta2 — iPad dock and Now Playing

- The dock mounts above the page at Spotify's navigation container. It clears the backing along the compact tab branch, including footer-sized sibling backings. The selected highlight sits inside the glass and tracks the current tab.
- Now Playing uses larger artwork and a readable artwork-derived background. The controls move below the art in split view and beside it in wide landscape. Spotify's header retains the native full-screen and split-view actions.
- One Lyrics action opens the configured lyric view. Beta 1's protection against cancelled lookups and the Spotify-lyrics fallback remain available.
- Studio has separate controls for the artwork-led player and bottom-bar glass.

The simulator checks that the dock responds to a changing backdrop, selection moves with the tab, and the native controls restore with glass off. Real Spotify layouts still need iPad testing. See [TESTING.md](TESTING.md) for the device checklist. This prerelease is separate from the stable feed.
