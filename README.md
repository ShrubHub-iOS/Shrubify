# Shrubify

A cleaner community fork of EeveeSpotify Reincarnated, built with native iOS 26 Liquid Glass options. Spotify's existing color palette is preserved.

**Start here:** [Complete setup, Codespaces import, release automation, and AltStore source](SHRUBIFY-SETUP.md).

**Upstream:** [Original project README](README-UPSTREAM.md) · [GPL-3.0 LICENSE](LICENSE) · Original tweak module files retained for compatibility.

No decrypted Spotify IPA is included in this repository. Public IPA distribution is opt-in and requires authorization.
